# 接続・基本操作・トラブル時の確認

## 接続

本体をUSBまたはMIDIで接続し、画面上部で機種を選びます。**接続** を開き、**本体からの入力** と音源に送る出力を指定します。設定を取得するには本体からの入力が必要です。

MU500をUSBで接続する場合は、本体の **HOST SELECT** を **USB** に設定します。USB出力1〜4をエディターのA〜Dに割り当てると、MU500の64パートを使えます。USBポート5〜8は、スルーポート設定で外部音源へのMIDI OUTに使えます。 [ヤマハ USB-MIDIドライバー](https://jp.yamaha.com/support/updates/usb-midi-driver-win.html)

## 本体からの取得

**本体から取得** で、すべて・エフェクト系のみ・ドラムマップデータのみから範囲を選びます。各ブロックを1回ずつ要求し、未取得の件数を終了時に表示します。未取得の項目には前回の値、または初期値が残ります。

## 音色とパート

- ミキサーでパートを選び、音色ブラウザーで音色をダブルクリックします。音色名や `99-0-42` のような番号で検索できます。画面のProgramは1〜128です。
- MU500のTG300Bでは、拡張音色とドラムキットも選べます。同じDrum Setupを使うパートは、キットとノート別設定を共有します。
- 数値欄は上下ドラッグ、ダブルクリック、直接入力で変更できます。初期値と異なる値は緑の太字で表示されます。
- 下部の鍵盤で試聴します。オクターブを下げるとドラムの低いノートを選べます。発音を止めるには **ALL NOTES OFF** を使います。

## 保存と本体への送信

**保存** でMUセット（JSON）またはSMF Format 1を書き出せます。SysExの読み込みと書き出しは **ライブラリー** で行います。本体から取得したデータは `userdata/backups/` にも保存されます。

SMFの書き出しと **本体へ送信** でも、取得時と同じ範囲を選べます。エフェクト系には割り当て、送り量、EQが含まれます。ドラムマップは各Drum Setupのノート別設定です。どちらの部分書き出し・送信でも、音色やドラムキットの選択は維持されます。シーケンサーでドラムキットを指定する場合は、Program Changeの後にドラムマップのSysExを置きます。

保存したMUセットを開き、**接続** してから **本体へ送信** を選びます。一括送信では先に本体の設定を取得・退避し、バルク送信した設定を読み戻して確認します。

**XG RESET** は、確認後にPC上の設定を退避し、本体をXGの初期状態に戻してから設定を読み直します。本体で変更した設定を残すには、初期化前に取得・保存してください。

## MIDIファイルの再生

下部の **MIDIファイル** からSMF Format 0または1を選び、接続した音源へ再生します。**曲の音色・設定を反映** を有効にすると、対応するBank Select、Program Change、設定SysExも送ります。初期化メッセージを含む曲は、本体の設定を変更する場合があります。

## 表示とトラブル時の確認

初回は日本語・ダークモードで起動します。言語は **編集 → 環境設定 → Language** で、テーマは画面上部のボタンで切り替えられます。

- **MUがポート一覧に表示されない** — 本体の電源、接続、ドライバーを確認します。
- **取得できない項目がある** — 機種、MIDI入出力、Device Numberを確認し、必要な範囲を再取得します。画面上部の **MIDIログ** で通信を確認できます。
