# 接続と基本操作

[README](../README.md) · [English guide](usage-en.md)

## 接続

本体のUSBまたはMIDI接続を準備し、エディターで機種を選びます。**接続** で本体からの入力と、音源に送る出力A〜Dを指定します。MU500のUSB接続では出力1〜4が音源用で、5〜8はMIDI OUTへのスルー用です。

接続後は **本体から取得** で本体の設定を確認できます。未取得の値は起動時の参考値です。取得結果に未取得項目が表示された場合は、MIDI接続を確認して再取得してください。

## 音色とパート

- ミキサーのパートを選び、音色ブラウザーで音色をダブルクリックします。検索には名前や `99-0-42` のような番号を使えます。画面のProgramは1〜128です。
- 数値欄は上下ドラッグ、ダブルクリック、直接入力で変更できます。太字の緑は初期値との差分です。
- パート編集、ドラム、エフェクトの各画面で機種に応じたパラメーターを扱えます。複数パートが同じDrum Setupを使う場合、ノート別編集を共有します。
- 下部の鍵盤で試聴します。オクターブを下げるとドラムの低いノートを選べます。発音を止めるには **ALL NOTES OFF** を使います。

## 保存と本体への送信

設定の取得結果は `userdata/backups/` に保存されます。**保存** で編集したセットをJSONまたはSMF Format 1に書き出せます。SysExの読み込み・書き出しはライブラリーにあります。

保存セットを開くとPC上に読み込まれます。適用するには **本体へ送信** を選びます。一括送信は本体の取得・退避を先に行い、バルク送信後に読み戻します。

**XG RESET** は確認後に本体をXGの初期状態に戻し、再取得します。実行前にはPCで保持している設定を退避します。本体で変更した設定を残すには、初期化前に取得・保存してください。

## MIDIファイルの再生

下部の **MIDIファイル** からSMF Format 0または1を選び、接続した音源へ再生します。**曲の音色・設定を反映** を有効にすると、対応するBank Select、Program Change、設定SysExも送ります。GM／GM2／XGの初期化を含む曲は、本体の設定が変わる場合があります。

## 表示と通信の確認

**編集 → 環境設定 → Language** で表示言語を切り替えます。画面上部のボタンでライト／ダークを切り替えられます。

取得が遅い、応答が途切れる場合は、機種とMIDI入出力の割当を確認します。上部の **MIDIログ** で通信を確認できます。詳細が必要な場合は、環境設定の **診断** でデバッグモードを選びます。[ログの内容と取り扱い](security.md)
