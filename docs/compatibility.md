# 対応機種と実機確認の範囲

[README](../README.md) · [English](compatibility-en.md)

| 機種 | 確認範囲 |
| --- | --- |
| MU500 | 実機確認済み |
| MU5、MU5K、MU10、MU15、MU50、MU80、MU90、MU90B、MU90R、MU100、MU100B、MU100Bs、MU100R、MU128、MU128 V2 | 仕様書ベース・実機未確認（注1） |
| MU1000、MU2000、各EX／EX R1 | 仕様書ベース・実機未確認・サポート対象外（注1、注2） |

- **注1**　入手性と需要を踏まえ、PLG対応機種（MU100、MU128、MU1000／MU2000系）の実機確認は予定していません。PLGのパート割り当ては、仕様書をもとに実装したVL／SG／DX用の試験機能です。PLGボードの動作は未確認で、ボード内部の音色編集は対象外です。
- **注2**　MU500との差分にあたるEFX 3／4、追加のバリエーションエフェクト27種、インサーションエフェクト54種は未確認です。MU2000のサンプル編集・波形転送は非対応です。

MU5系は専用のMIDI形式を使います。主な編集対象はXGです。パート数、音色マップ、エフェクト、A/D入力などの項目は機種と動作モードによって異なります。
