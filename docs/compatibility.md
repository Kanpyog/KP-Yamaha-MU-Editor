# 対応機種

[README](../README.md) · [English](compatibility-en.md)

| 機種 | 確認範囲 |
| --- | --- |
| MU500 | 実機確認済み |
| MU5、MU5K、MU10、MU15、MU50、MU80、MU90、MU90B、MU90R、MU100、MU100B、MU100Bs、MU100R、MU128、MU128 V2 | 仕様書ベース・実機未確認 |
| MU1000、MU2000、各EX／EX R1 | 仕様書ベース・実機、EFX3/4、バリエーションエフェクト27種、インサーションエフェクト54種未確認  |

MU5系は専用MIDI形式を使います。機種と動作モードによって、パート数、音色マップ、エフェクト、A/D入力などの項目が異なります。XGが主な編集対象です。

PLGのパート割当はVL／SG／DX種別の試験機能です。追加基板の実機動作と内部音色編集、MU2000のサンプル編集・波形転送は対応範囲外です。
