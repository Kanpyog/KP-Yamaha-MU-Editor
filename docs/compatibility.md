# 対応機種 / Compatibility

[日本語](../README.md) · [English](../README_EN.md)

Windows 11 x64向けです。実機で開発・動作確認した機種はMU500です。ほかの機種は仕様書に基づくプロファイルを選べます。

The Windows build targets Windows 11 x64. The MU500 is the development and hardware test unit. Profiles for the other models are based on Yamaha documentation.

| 機種 / Models | 確認範囲 / Status |
| --- | --- |
| MU500 | 実機確認済み / Hardware tested |
| MU5、MU5K、MU10、MU15、MU50、MU80 | 仕様書ベース・実機未確認 / Documentation-based, untested on hardware |
| MU90、MU90B、MU90R、MU100、MU100B、MU100Bs、MU100R、MU128、MU128 V2 | 仕様書ベース・実機未確認 / Documentation-based, untested on hardware |
| MU1000、MU2000、各EX／EX R1 | 実機未確認・サポート外 / Untested on hardware and unsupported |

MU5系は専用MIDI形式を使います。機種と動作モードによって、パート数、音色マップ、エフェクト、A/D入力などの項目が異なります。XGが主な編集対象です。

MU5 models use their native MIDI format. Part counts, voice maps, effects and A/D input controls vary by model and operating mode. XG is the primary editing mode.

PLGのパート割当はVL／SG／DX種別の試験機能です。追加基板の実機動作と内部音色編集、MU2000のサンプル編集・波形転送は対応範囲外です。

PLG part assignment is experimental for VL, SG and DX board types. Plug-in boards have not been verified on hardware. Board voice editing, MU2000 sample editing and waveform transfer are unsupported.
